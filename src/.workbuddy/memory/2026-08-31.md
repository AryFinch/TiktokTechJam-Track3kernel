## Key insights
- Optimized median is pinned at ~1.0–1.3 ms across all feasible rows; speedup
  comes almost entirely from the baseline getting slower (S×S score matrix
  materialization). SDPA's win scales with problem size on every axis.
- SDPA can LOSE on tiny models (d_model=32 → 0.87×): latency-bound, fused
  kernel less efficient at head_dim=8 on MPS.
- Row 14 is impossible for the baseline by construction: attention scores
  would be ~20 TB fp32. Died at accuracy stage (MPS OOM at ~49 GiB). This
  row is the canonical argument for O(S) streaming attention.
